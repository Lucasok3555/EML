## como funciona a criptomoeda
ele permite ao cuidar e para mim guardar dinheiro via protocolo Nostra aonde ninguém controla o seu dinheiro de fato boxe é o dono do seu próprio dinheiro O sistema funciona desse jeito
você tem essa chave pública ela vai servir como um endereço para você receber dinheiro
e a chave privada vai ser responsável para você recuperar a conta e recuperar o dinheiro de fato
esse sistema permite vários sistemas de moedas diferentes seja criada de fato para isso usamos
o foco da moeda tem uma alternativa ao Bitcoin e o sistema de um financeiro alternativo
e no futuro a gente vai poder converter o seu dinheiro no banco ou de sujeira real de outras moedas direto para a moeda de fato
a plataforma pode existir várias moedas dentro de uma de moeda
e também pode você ganhar moedas você pode ganhar de várias maneiras diferentes usando poder e processamento ou vazio no contos ou deviam no letras
